# Intake question rubric

Use this to judge whether a candidate question is worth asking.

## Keep if

| Criterion | Pass example |
|-----------|----------------|
| Changes writing | Different answer → different chapters, emphasis, or comparisons |
| Human-answerable | Planner can answer without looking up tables |
| Gap-focused | Brief does not already settle the point |
| Scope / decision | Time, region,口径, baseline, reader decision, hard constraints |

## Drop if

| Criterion | Fail example |
|-----------|----------------|
| Filler | "请补充更多背景信息" |
| Already in brief | Asking for a fact clearly stated in vault excerpts |
| Number trap | "请给出 2030 年管输量精确值" |
| Trivia | Definitions or history with no planning stake |
| Org identity | Asking whether「本集团」is 国家管网 / other companies — identity is product-fixed |

## Prefer order

1. Planning horizon / target year  
2. Geographic or business-line boundary  
3. Comparison baseline (peer, prior plan, national average)  
4. Reader decision this report must support  
5. Must-include / must-exclude topics  
6. Known constraints (policy, capital, schedule)  
7. Priority when goals conflict  
8. One open gap the user may already know from operations
