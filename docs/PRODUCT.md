## 1. 一句话定位

RealAi 是面向战略规划的本地优先知识与写作工作台：以 Obsidian Vault 管理知识，以 DeerFlow 二次开发承载智能能力，支持循证问答、Excel 精确问数、多模态检索和可恢复的长报告写作。

当前主产品形态为：

- Vue 3 Web 主界面；
- macOS Electron 桌面端；
- Python/FastAPI Gateway；
- Windows 便携目录是主要交付目标；打包脚本需在 Windows 构建机生成原生运行时。

---

## 2. 产品硬约束

1. Web 与 Electron 共用 `apps/web` 的 Vue 主前端；封存的 DeerFlow React 页面不是主入口。
2. DeerFlow 二开后端是唯一智能主引擎，不另建平行 Agent 引擎。
3. Obsidian Vault 是知识真相源；SQLite 和 DuckDB 是运行时元数据与查询引擎。
4. 模型、联网、看图、Skill 和写作过程必须可审计、可配置、可降级。
5. 问数结果来自确定性查询或只读 SQL，不允许模型直接给出未经执行验证的数字。
6. 报告无有效且已确认的大纲时不得写正文；章节顺序只由大纲决定。
7. 具体数字必须绑定 `kb:`、`data:`、`viz:` 或 `web:` 证据。
8. 长任务显示业务阶段和工具动作，不展示模型私有思维链。
9. 已完成章节必须服务端持久化，页面退出后不得丢失。
10. 主路径不要求用户安装 Docker。

## 3. 核心用户路径

### 3.1 知识导入

```text
上传 Word/PDF/Excel/PPT/图片
→ 查看任务与文件级进度
→ 解析、去重、分类和质量门禁
→ 查看原文/工作表
→ 进入检索与问数
```

知识库与写作范围统一为七类；工作台当前仍按 Vault 物理目录选范围：

`文档资料 / 结构化数据 / 图片与多媒体 / 知识卡片 / 实体与关系 / 指标与规则 / 报告与成果`

### 3.2 轻量问答与问数

```text
选择知识范围
→ 输入问题
→ 知识检索 ± 结构化问数 ± 看图 ± 联网
→ 结论、表格或图表
→ 证据栏核对原文、行列和口径
```

- 单值问题直接返回数值和来源，不生成无关图表。
- 趋势、对比、排名和分布在数据适合时生成图表。
- 表选择置信度不足时明确拒答或请求补充，不拿无关预览行充数。

### 3.3 战略报告

```text
描述写作目标
→ 智能补缺（充分则跳过，最多补问 2 题）
→ 资料研究
→ 生成并确认大纲
→ 1～3 章并发 Token 流式写作
→ 全文统一引用
→ 七维评审与局部优化
→ 按章/整篇编辑
→ 导出 Markdown / Word / PDF
```

报告恢复规则：

- 大纲是章节编号和顺序的唯一来源；
- 完整章节完成即写检查点；
- 前端断线后重新读取服务端状态；
- 继续运行从第一个缺失章节开始；
- 暂停、终止和删除均保留明确状态。

## 4. 主要页面

|页面|能力|
|---|---|
|工作台|多会话、问答/问数/检索、知识范围、表图、证据和轨迹|
|战略规划生成|新建、智能补缺、大纲、流式逐章、评审、编辑、导出|
|知识库|七类目录、导入进度、原文预览、健康度、索引治理|
|知识图谱|实体、关系和来源浏览|
|Skill|业务 Skill 新建/导入/试跑/启停；系统内置只读|
|模型|模型清单、双协议、主/高速/备用路由；视觉角色当前预留|
|评测|套件、用例、异步跑批、逐题详情和回归对比|
|设置|Vault、联网、看图、报告参数和健康检查|

## 5. 核心 Agent

|ID|职责|
|---|---|
|`intake`|本地提取时间、区域、范围、目标、读者和硬约束，仅按需补问|
|`researcher`|知识检索、问数、白名单联网和事实包|
|`architect`|正式标题、战略主线和章节大纲|
|`writer`|按大纲并发流式逐章写作|
|`citer`|全文统一引用并生成 `## 参考文献`|
|`reviewer`|七维评审与确定性检查|
|`optimizer`|围绕薄弱章节局部优化|

轻量问答不运行整套报告流水线。

---

## 6. 当前验收重点

- 新上传文件有进度、失败原因和原文预览。
- 新上传 Excel 可直接精确问数。
- 图表生成遵守意图和数据质量门禁。
- 智能补缺可自动跳过或最多询问 2 题。
- 大纲生成并确认前正文写作不可启动。
- 第一章和首个缺失章顺序规则不被并发事件破坏。
- Token 增量可见，页面退出后章节不丢失。
- 全文完成后统一输出 `## 参考文献`。
- 预览支持字体缩放，大纲和“第 N 章”字号可读。
- 写作任务可暂停、继续、终止、重跑和删除。
- Skill 新建必须先试跑；系统内置 Skill 只读。
- 评测结果来自真实跑批，无跑批时不展示虚假通过率。
